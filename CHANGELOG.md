# NHibernate.ObservableCollections - Changelog


## 5.0.0 (2025-11-11)

### All

Improvements:
- Added support for **`.NET 9.0`**.

Breaking Changes:
- Removed support for **`.NET 7.0`** and **`.NET 6.0`**.
- Replaced **`IndexRange`** with **`Microsoft.Bcl.Memory`**.

### NHibernate.ObservableCollections

Breaking Changes:
- Updated **`NHibernate`** to 5.5.2.


## 4.0.0 (2024-11-12)

### All

Improvements:
- Added support for **`.NET 8.0`**, **`.NET 7.0`**, and **`.NET 6.0`**.

### NHibernate.ObservableCollections

Breaking Changes:
- Updated **`NHibernate`** to 5.4.0.
